## Основные возможности

* Сбор метаданных статей из arXiv.
* Получение полного текста PDF-документов.
* Извлечение и очистка текста с использованием GROBID.
* Извлечение ссылок на цитируемые статьи arXiv.
* Разделение статьи на логические секции.
* Сохранение результатов в PostgreSQL.
* Автоматическое удаление временных файлов и устаревших логов.
* Оркестрация всех процессов через Apache Airflow.

# Компоненты системы

## parser_dag.py

Основной DAG сбора данных.

Этапы обработки:

1. Получение новых статей из arXiv.
2. Загрузка дополнительной информации через API arXiv.
3. Загрузка PDF-файлов.
4. Извлечение очищенного текста через GROBID.
5. Извлечение списка цитируемых arXiv-статей.
6. Сохранение результатов в PostgreSQL.
7. Запуск DAG обработки секций статьи.

---

## section_parser.py

DAG для структурирования текста статьи.

Выполняет:

* повторную обработку PDF через GROBID;
* выделение секций документа;
* удаление служебных разделов;
* очистку неинформативных секций;
* объединение коротких фрагментов;
* сохранение структуры статьи в формате JSON.

---

## base.py

Содержит:

* базовые настройки Airflow;
* настройки подключения к PostgreSQL;
* общие константы проекта.

---

## clean_dataframes.py

Служебный DAG.

Удаляет временные CSV-файлы старше установленного периода хранения.

---

## clean_logs.py

Служебный DAG.

Удаляет устаревшие логи Airflow для предотвращения переполнения дискового пространства.

# Запуск проекта

## Предварительные требования

На сервере должны быть установлены:

* Docker
* Docker Compose

Также должен быть запущен сервис GROBID, доступный по адресу:

```text
http://grobid:8070
```

---

## Сборка контейнеров

```bash
docker compose build
```

---

## Запуск сервисов

```bash
docker compose up -d
```

После запуска будут доступны:

| Сервис         | Адрес                 |
| -------------- | --------------------- |
| Airflow Web UI | http://localhost:8080 |
| Flower         | http://localhost:5555 |

# Результат работы

Для каждой статьи в базе данных сохраняются:

* идентификатор статьи;
* название;
* аннотация;
* категории;
* дата публикации;
* авторы;
* ссылка на PDF;
* очищенный текст статьи;
* список цитируемых arXiv-статей;
* структура статьи по секциям в формате JSON.
